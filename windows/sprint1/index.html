🖥️1 - Màquina virtual.exe

1. Màquina virtual, instal·lació i particions

Una màquina virtual és un ordinador simulat que funciona dins del teu. Hi instal·lem Windows a partir d'una imatge ISO i repartim el disc en particions, és a dir, en parts independents que el sistema veu com a unitats separades.

1.1 · Crear la màquina virtual

A VirtualBox es crea la màquina amb la ISO de Windows 11, 8192 MB de RAM, 4 CPU i un disc virtual de 80 GB (VDI), amb «Utilitza EFI» activat.

1.2 · Xarxa de la màquina

A Configuració → Xarxa es comprova que l'Adaptador 1 està habilitat i en mode NAT.

1.3 · Instal·lació de Windows

Es carrega la ISO i es comença la instal·lació: idioma, teclat, opció d'instal·lació, edició (Windows 11 Pro) i resum final. Després l'instal·lador continua sol amb diversos reinicis.

1.4 · Particions

A la pantalla de particions es crea una partició per a Windows. Windows crea sol les petites del sistema (System i MSR), cosa normal en un disc UEFI/GPT.

ParticióMidaTipusÚs
Partition 1200 MBSystemArrencada (EFI)
Partition 216 MBMSR (Reserved)Reservada per Windows
Partition 360 GBPrimaryWindows (C:)
Partition 419,8 GBPrimaryDades

1.5 · Partició DADES (D:)

Quan Windows arrenca, s'obre diskmgmt.msc (Administració de discs) i es deixa la partició de dades en format NTFS, amb el nom DADES i la lletra D:.

🔑2 - Llicències.exe

2. Llicències

Windows no és gratuït: per fer-lo servir legalment cal una llicència activada. N'hi ha de diferents tipus: Retail (es compra a part i es pot passar a un altre equip), OEM (ve amb l'ordinador i hi queda lligada) i de volum (per a empreses i centres). Als servidors, a més, hi ha les CAL.

2.1 · Estat de l'activació

Configuració → Sistema → Activació: edició de Windows i si està activat.

2.2 · slmgr

Al cmd: slmgr /xpr (estat de l'activació) i slmgr /dli (tipus de llicència).

2.3 · Preus

Preu de Windows 11 Home i Pro a la botiga oficial de Microsoft i a una altra botiga.

2.4 · Què és una CAL

Què és una CAL (Client Access License), segons la web de Microsoft.

⌨️3 - Comandes bàsiques.exe

3. Comandes bàsiques

La línia de comandes permet donar ordres a l'ordinador escrivint, sense finestres ni ratolí. És més ràpida per a moltes tasques i és l'eina habitual per administrar sistemes. Es fa servir el Símbol del sistema (cmd).

3.1 · Carpeta de pràctica

cd Desktop, mkdir practica i cd practica.

3.2 · Crear un fitxer

echo hola > nota.txt i comprovació amb dir.

3.3 · Copiar

copy nota.txt copia.txt i comprovació amb dir.

3.4 · Crear una carpeta i moure

mkdir arxiu i move copia.txt arxiu.

3.5 · Canviar noms

ren nota.txt notes.txt, ren arxiu backup i comprovació amb dir.

3.6 · Entrar i sortir d'una carpeta

cd backup, dir i cd ...

3.7 · Estructura

tree /f mostra l'estructura de carpetes i fitxers.

3.8 · Esborrar un fitxer

del notes.txt i comprovació amb dir.

3.9 · Netejar la pantalla

cls neteja la pantalla del terminal.

📦4 - Aplicacions i restauració.exe

4. Aplicacions i punts de restauració

Un punt de restauració és una còpia de l'estat del sistema (programes, configuració i registre) en un moment concret. Si després d'instal·lar alguna cosa el sistema falla, es pot tornar a aquell punt sense esborrar els documents personals. Es prova instal·lant Google Chrome.

4.1 · Crear el punt de restauració

Es busca Crear un punt de restauració, s'activa la protecció del sistema al disc C: i es crea un punt anomenat Abans de Chrome.

4.2 · Instal·lar Chrome

Es descarrega Chrome de la web oficial de Google, s'instal·la i s'obre.

4.3 · Programes afectats

A Restaurar sistema es tria el punt creat i es prem Cerca programes afectats: hi ha d'aparèixer Chrome.

4.4 · Restaurar el sistema

Es restaura el sistema i es comprova que Chrome ja no hi és.

🌐5 - Xarxa.exe

5. Xarxa

Per tenir Internet, l'equip necessita una adreça IP, una connexió activa i un servidor DNS, que tradueix noms com google.com a adreces IP. Fent ping a un nom i a una IP es pot saber si hi ha connexió i on falla.

5.1 · Adaptador en NAT

Amb l'adaptador en NAT: ipconfig, ping google.com i ping 8.8.8.8.

5.2 · Cable desconnectat

A VirtualBox, Dispositius → Xarxa, es desmarca Connecta el cable i es repeteixen els dos ping.

5.3 · Adaptador pont

Es torna a connectar el cable i es canvia l'adaptador a Adaptador pont. Es repeteixen ipconfig i els dos ping.

5.4 · DNS manual

A Windows es posa el DNS manual 1.2.3.4 i es repeteixen els dos ping. Després es torna a posar el DNS en automàtic.
