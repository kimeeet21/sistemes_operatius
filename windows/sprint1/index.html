💿1 - Instal·lació SO.exe

Instal·lació del sistema operatiu

Es descarrega la ISO de Windows 11 (x64) des de la web de Microsoft i la màquina s'arrenca des d'ella. L'instal·lador demana, per ordre: idioma (English (United Kingdom)), teclat (United States-International), l'opció Install Windows 11, la clau de producte, l'edició (Windows 11 Pro) i el disc de destí (vegeu l'apartat Particions). Abans d'instal·lar mostra un resum, Ready to install.

La instal·lació es fa en diverses etapes i l'ordinador es reinicia sol unes quantes vegades.

🗂️3 - Particions.exe

Particions

El disc virtual de 80 GB apareix com a espai sense assignar. S'hi crea una partició de 61 440 MB (60 GB) per a Windows; en fer-ho, l'instal·lador crea sol les particions pròpies d'un sistema UEFI/GPT. Amb l'espai que queda es crea una segona partició de dades, i Windows s'instal·la a la de 60 GB (Partition 3).

🖥️4 - Virtualització.exe

Virtualització

A VirtualBox es crea una màquina nova amb el nom WINDOWS11, la ISO oficial Win11_25H2_EnglishInternational_x64_v2.iso i el sistema Microsoft Windows · Windows 11 (64-bit), sense la instal·lació desatesa perquè l'assistent es faci a mà.

Maquinari: 8192 MB de RAM, 4 CPU i l'opció «Utilitza EFI» activada (Windows 11 arrenca en mode UEFI). Disc dur virtual nou de 80 GB en format VDI.
